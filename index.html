Direct Messenger

Peer-to-peer chat · One HTML file · No message server

1. Start a connection

Person A

Create an offer, then send the generated code to the other person using any method you choose.

After they send you their answer code, paste it here.

2. Join a connection

Person B

Paste the offer code you received, create an answer, then send the answer code back to Person A.

Messages

Not connected
Connect with another browser to start chatting.
Privacy & limitations: Messages travel directly between the connected browsers using WebRTC data channels; this page does not store or relay them. The offer and answer codes are exchanged manually. A public STUN server is used to help establish connections, and some networks may require a TURN relay, which would no longer be fully serverless. Use HTTPS or localhost if your browser restricts WebRTC features.

Connection codes contain temporary session details. Share them only with the person you intend to connect with. This demo does not provide persistent identities, message history, or end-to-end identity verification.
