Welcome to Flapchat

A peer-to-peer chat and server platform. Sign in on multiple devices to link them, then create or join servers.

Servers: Create a server below or ask someone for an invite link.

Direct messages: Search for or navigate to another user's profile to start chatting.

Data is stored locally and synced to your linked devices over peer-to-peer connections. Servers and messages are not encrypted in this prototype.
